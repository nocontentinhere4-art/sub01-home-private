NEW, FOUND LIVE AFTER YOUR REVIEW (the real cause of the missing Control chords)
Vagon's client bundle (keyDownHandler/startPendingCtrl) holds a Left-Control keydown 15 ms to detect AltGr and, when
another non-modifier key arrives inside that window, calls flushAsRealCtrlNow(), which only clears the timer: both the
key and the pending Control are dropped (measured: Ctrl+A = 2 keydowns but only the 2 keyups on the control channel;
Ctrl+Escape the same). Fix: _vagon_chord presses modifiers down, waits VAGON_CHORD_HOLD_S = 0.1 s, presses the key,
releases the modifiers in a finally; the scancode path (_keys) waits after a Control keydown in vagon mode. The
Control+Escape -> Meta alias was removed. Live after the fix: Ctrl+A selects the remote text (8 control messages),
Delete clears it, Ctrl+Escape opens the Start menu.
