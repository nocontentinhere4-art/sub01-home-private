WHAT THE DIFF DOES
1. parse_key accepts a lone modifier (Meta, Control, Alt, Shift).
2. RTC_INIT_JS (every frame via context.add_init_script): keeps at most 8 peer-connection records, dropping a finished
   one before a live one; first stats poll after 1 s; counts outbound data-channel messages per label and WebSocket sends
   (counts and bytes only). Measured: the init script also runs in a script-created about:blank iframe, so no extra hook.
3. INPUT_INIT_JS (vagon mode, every frame): wraps EventTarget.prototype.addEventListener to COUNT listeners by target and
   type; capture/bubble listeners on window count key/mouse/wheel events, their last target, how many bubbled back and how
   many were prevented; requestPointerLock / keyboard.lock calls; pointerlockchange / fullscreenchange. Never a key value.
4. VAGON_DIAG_JS: an input block (active element, pointer lock, fullscreen, what is at centre/top/bottom, the hook
   counters, a 5x4 cover grid over the largest video with background/opacity of any covering element).
5. VAGON_HIT_JS: a click/wheel/hover point is accepted only when the top element is the stream element or inside it (your
   advice); everything else is classified (host control, a layer that paints = dim/backdrop, transparent layer, container,
   outside, no stream) and refused. On a real page an evaluate error refuses the input too.
6. _vagon_input: click -> hit test, move, click; scroll -> hit test at the last point used on the stream (else the
   centre), move, six wheel steps; key/type/navigate/back -> _vagon_keys_ready (once per session: hit test + mouse move to
   the stream, never a click; then the video's DOM focus every time) then the keys. "Control+Escape" is sent as "Meta"
   (VAGON_KEY_ALIASES). No automatic activation click (measured unnecessary; a click lands in a remote window).
7. _rtc_summary prefers a live connection (state connected) over a finished one with more bytes (the old summary showed
   the previous session's closed connection); a follow-up diag 8 s after connect (the first comes before any stats);
   a diag every 60 s while connected; GET /pc/vagon/diag (token) for a fresh snapshot, at most one per 2 s.

8. NEW, measured live after the first review request: Ctrl+A dimmed the whole stream again. The player prevented 14 of
   16 keydowns (Meta, Escape, typed characters, Delete) but not Control and Ctrl+A, so Chrome also ran the HOST page's
