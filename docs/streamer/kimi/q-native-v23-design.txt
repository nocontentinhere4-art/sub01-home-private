PROPOSED v23 (every new key's default leaves today's look bit-identical: the new code path is skipped at the default).
A. Posture (proxy, before the IK so the IK re-plants the hands):
   pelvis_pitch_deg (-20..20, default 0): Hips turned about his lateral axis (FORWARD degrees, negative = sit up; same sign as
     the lean), both UpLegs counter-rotated so the thighs stay on the seat (a hip hinge, not a spine backbend);
   shoulder_drop_deg (-10..20, default 0): both clavicles (Left/RightShoulder) turned down about his forward axis;
   shoulder_back_deg (-10..20, default 0): clavicles retracted (turned back about the vertical);
   neck_back_deg (-15..20, default 0): "chin tuck": Neck turned back (extension) and Head forward by the same angle, so the head
     moves back over the shoulders with the face orientation kept.
B. Neck / hood seam (proxy):
   neck_share (-1 or 0..1, default -1 = today's 0.4): the Neck's share of the head channel (rest on Head); 0 keeps the neck skin
     with the hood ring when the head pitches/yaws;
   neck_girth (0.8..1.4, default 1): radial scale of the Neck bone (the two axes across the Neck->Head direction), the Head
     compensated exactly (inverse scale and translation) so only vertices weighted to Neck swell - to close the skin gap.
   (Existing live diagnostic: hide_slot 4/5 hides hood_lining / hood_patches.)
C. Elbow stretch (proxy IK):
   elbow_min_deg (0..150, default 0 = off): if the wrist target would bend the elbow tighter than this, the target slides FORWARD
     along his facing at the same height until the elbow interior angle equals the minimum (no hand pushed into the desk);
   elbow_pole_back / elbow_pole_out (-1 = today's 0.5 / 0.3, else 0..1.5): the pole's back and outward weights (down stays 1),
     to keep the elbow beside the torso instead of behind it.
D. Hands (proxy IK, after the arm solve):
   hand_orient (0..1, default 0): the hand bone turned (in component space, about the wrist) so the fingers (Hand->Middle1) point
     along his facing, yawed inward by hand_yaw_in_deg (default 12, range -30..45) and pitched down by hand_pitch_deg (default 10,
     -30..60), with the knuckle line (Index1->Pinky1) horizontal and the pinky outward (palm down follows from handedness);
     blended by orient * IK alpha. Axis-agnostic: built from bone POSITIONS, not local axes.
   finger_bend_deg (0..60, default 0): index..pinky phalanges 1/2/3 bent by 1.0/1.2/0.6 x the value about the knuckle axis,
     towards the palm side computed from the hand geometry (right hand: palm side = -(F x A), left: +(F x A)), axis-agnostic
     (the existing finger_curl_deg uses a guessed local axis).
   mouse_scan (0/1, default 0): when no mouse actor exists, scan primitive COMPONENTS (bounds centre in the mouse zone, half
     extents <= 12/12/8, not desk/keyboard pack meshes), take the one nearest mouse_x/y/z, make it Movable and move it with the
     keyboard pull-back; it then becomes the right hand's mouse target;
   hand_on_mouse (0/1, default 0): the right hand on the mouse in every state except typing (left hand stays on the keys).
E. Face light (character, after the existing key light update; extra lights created lazily, lighting channel 1 like the key):
   key_side_cm (extra side offset of the key, default 0, -80..80), key_up_extra_cm (default 0), key_specular (default 1, 0..1);
   fill_cd (0..2, default 0 = no light), fill_side_cm (default 45 to his right), fill_up_cm (default 0), fill_temp_k (default 5000);
   rim_cd (0..2, default 0), rim_back_cm (default 60), rim_side_cm (default -30), rim_up_cm (default 40), rim_temp_k (default 6500).
F. Chair (character):
   chair_back_extra_cm (-10..30, default 0): extra distance of the whole chair along his facing AFTER the fit (the fit measures
     the backrest without it, so it does not cancel it), eased at 60 cm/s;
   chair_side_cm (-15..15, default 0): chair sideways only;
   chair_scale (1..1.3, default 1): chair parts scaled horizontally about the seat pivot (a slightly wider frame around the
     oversized hoodie).
